网站入口与个人信息安全加固

网站已加强后台和玩家身份的访问隔离、跨站写入拦截、脚本执行白名单、匿名身份创建限流、来源网络限流与上传空间保护。外部链接和玩家自带模型地址也会检查内网、云元数据及 DNS 重绑定风险，并限制为公开网页入口。个人空间的搜索发现、身份展示和在线统计开关继续有效。

2026-11-27
用户与创作者隐私保护中心上线

现在可以在“个人 → 隐私保护中心”阅读匿名身份、公开内容、AI 数据处理与数据权利说明，并管理搜索发现、个人空间、活动身份、在线统计和新剧本默认可见范围。你也可以导出或删除当前匿名身份下的个人数据。

2026-11-27
底部导航与全屏工作区更新

主页、联机页和私人空间现在始终显示底部导航。剧本创作、社区、官方公告与投诉反馈、个人页默认使用全屏布局，也可以在各页面右上角随时切换为缩放视图。

2026-11-26
剧本封面与背景可以自由裁剪了

创作者现在可以自己决定画面怎么摆：填充方式（填满裁剪 / 完整显示）、横向焦点、纵向焦点、裁剪缩放（100%–220%），编辑器里有实时预览，封面在剧本书架和详情页同步生效。剧本背景另外支持背景缩放（100%–200%）与焦点位置，仍然只在对局页作为正文背景显示。上传封面时 JPG / PNG / WEBP / GIF 都可以，背景图只接受静态图片。

2026-11-26
接任意模型都不再“状态不同步”

修复了使用 Gemini、Claude、本地 Ollama 等模型时，正文正常但右侧状态栏（生命/理智/背包/时间）不更新的问题。现在能识别各家模型五花八门的标签写法、自动修补格式错误；如果模型的输出被长度限制截断，系统会自动补问一次状态，把这一回合的数值补全。

2026-11-26
本地模型的提示更清楚了

在“AI 模型”里填 127.0.0.1 这类本机地址时会明确说明：模型请求由网站服务器发出，线上站点访问不到你家里的电脑。页面会给出两种可行做法——在本机运行站点，或者给本地模型开一个公网隧道。

2026-11-26
剧本封面支持 GIF 动图

封面现在可以上传 JPG / PNG / WEBP 静态图，也可以上传 GIF 动图，卡片上会直接动起来。剧本背景图仍然只接受静态图片，并且只在对局页作为正文背景显示，不会出现在剧本书架和详情页。

2026-11-26
剧本搜索与可见范围

“选剧本”新增搜索框，可以按剧本名、作者、关键词、标签和详细介绍搜索。新建或编辑剧本时还能设置可见范围：公开（所有人可见）、指定联系人可见（填对方的随机玩家 ID）、仅自己可见。非公开剧本不会出现在别人的列表里，直接拿到链接也打不开。

2026-11-26
玩家协议确认只在开局弹一次

以前每次提交行动都要勾选一次协议，现在默认只在本局第一次行动前确认一次，之后整个对局不再打断你。想改回来可以到右侧面板「协议」里切换：只弹一次 / 每次行动都弹 / 从不弹窗（协议内容仍会随行动发送给叙事引擎）。

2026-11-26
难度选项与界面细节调整

跑团规则的难度选项改成紧凑横条，字号随屏幕自动适配，不再占满整屏。另外公开入口已经不需要邀请码，直接打开网址就能开始游玩。

2026-11-26
公共剧本库开放

所有玩家创建、导入或上传的剧本都会自动出现在公共剧本库中，其他玩家可以查看和游玩，但只有作者本人可以修改或删除。

2026-11-26
独立剧本页面与社区推广上线

现在可以把剧本发布到社区推广，也可以生成独立的剧本页面链接分享到其他平台。

用户与创作者隐私保护协议 · 2026-11-27

身份与账号：本站以浏览器内的匿名随机标识区分玩家，不要求真实姓名或密码。更换浏览器、使用无痕模式或清除站点 Cookie 可能导致你无法继续控制原有资料和作品。

收集的数据：昵称、简介、头像、私人笔记、主题与语言设置；剧本、角色预设、社区帖子、留言、评论、房间与游玩存档；为运行和安全目的产生的在线状态与基础访问信息。

公开内容：设置为公开的剧本、社区帖子、留言、评论、昵称和头像可能被其他玩家看到、复制或转发。请勿发布身份证号、住址、电话、账号密码、API Key 或其他敏感信息。设置为“仅自己”的剧本不会出现在他人剧本列表中。

创作者权利：创作者保留其原创作品署名权，可随时修改署名、可见范围或删除自己的剧本。平台仅按你的可见性设置存储、展示和提供给符合范围的玩家游玩，不会把作品冒充为平台原创。

联系人可见：联系人范围只依据对方不可自行伪造的随机玩家 ID 匹配。昵称可被任意修改，因此不再作为访问控制凭据。联系人可见仍不等同于高强度加密，请勿用它承载账号密码、真实住址或其他高风险秘密。

AI 处理：只有开局、回合推演和联机推进需要把当前剧情、角色、设定和行动发送到所选 AI 服务。使用网站默认模型时数据发送到网站配置的模型服务商；使用自定义 API 时发送到你填写的服务商。本站不把这些内容用于出售或广告画像，也不会把密钥展示给其他玩家。

保存与删除：你可以在下方导出个人资料、剧本、预设、存档、帖子和留言，也可以删除当前浏览器身份下的个人数据。删除会移除服务器中的对应活动数据；已被他人复制、转发的内容无法追回，手动备份文件也可能保留历史副本。

你的选择：你可以关闭搜索发现、个人空间、活动身份展示和在线人数计入，也可以设置新剧本默认仅自己、联系人可见或公开。关闭活动身份不会删除已有公开内容，但之后显示的昵称和头像会匿名化。

隐私与展示设置
