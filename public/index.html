多人联机大厅与房间系统全面升级

主页入口：主页新增醒目的多人联机区域，可以直接查看“进入联机大厅”和“匹配大厅”入口，也可以在主页展开快速建房。快速建房支持选择剧本、玩法、难度、房间类型、人数上限、每轮倒计时、旁观、自动推进和开局设定，并可详细填写角色背景、外貌、性格、能力、目标与六项属性。

预置开场回合：联机开局不再只显示一条模糊钩子。点击开始游戏后，会立即写入“剧本序章”“队伍与在场人物”“第一回合选择”三个预置段落，并给出与当前地点、NPC 和剧本钩子对应的行动方向。房主也可以从剧本已有开场选项中选择，或填写自己的详细开场；预置开场直接写入房间正文，不调用 AI、不额外消耗模型额度。AI 会从这些已发生的开场事实继续推演。

房间类型与匹配大厅：联机房间现在分为公开房、密码房和私密邀请房，支持 2–8 人。公开房和密码房会进入公开房间列表，可按剧本、房间码、玩法、状态搜索并快速匹配；私密邀请房不进入公开列表，只能通过房主生成的随机邀请链接进入。房间密码使用 scrypt 加盐哈希，不保存明文。

旁观与席位：房主可决定是否允许旁观，开始后的对局仍然可以让新玩家进入旁观席。每个房间最多保留 12 个旁观席位；旁观者可以阅读剧情、世界状态、聊天和历史，但不能准备、提交行动或推进剧情。

独立准备与开始：每位玩家拥有独立准备按钮；所有玩家都准备后，房主才能开始游戏。玩家在线、离线、准备、已行动、被禁言和语音状态会分开显示，不再把“提交行动”误当作大厅准备。

房主管理：房主可以踢出玩家或旁观者、禁言 15 分钟、解除禁言、永久禁言和转让房主，也可以修改密码、人数、旁观权限、每轮倒计时和自动推进。被踢玩家 24 小时内无法重新进入同一房间；房主离开时会自动把房主身份交给下一位在线玩家。

倒计时、超时托管与自动推进：每轮具有服务端倒计时。到时仍未提交行动的玩家会自动进入超时托管；房主开启自动推进后，任何一位仍在房间的玩家都可以在倒计时结束后触发下一轮推演。服务器使用房间忙碌锁防止多人同时触发、重复生成或重复消耗额度。

聊天与剧情分离：房间聊天与剧情正文彻底分开保存。聊天不会进入 GM 提示词，也不会混进剧情日志；剧情正文、玩家行动、系统通知、开场回顾和世界状态仍各自保留。聊天消息支持时间显示、玩家身份和旁观标签，禁言会直接阻止发送。

历史与断线重连：每完成一轮都会生成独立回合存档，保留本轮行动、正文、建议和状态变化。房内可按页浏览完整历史存档。网络中断时页面会显示重连状态并自动继续轮询；玩家在线状态会按心跳时间实时更新。

房间语音与语音输入：房间内新增 WebRTC 点对点语音，可加入语音、开关麦克风、查看其他语音成员状态和离开语音。浏览器支持时会额外提供“语音输入”，把口述内容转换到行动框中。语音音频不会写入房间存档；严格 NAT、企业防火墙或缺少 TURN 服务时，点对点语音可能无法连通。

跨实例恢复验证：房主可导出带校验和 HMAC 签名的恢复快照，导入前会验证快照完整性、原房主身份和共享会话密钥，篡改文件会被拒绝。导出时会等待本轮推演结束，避免保存半步状态。快照是人工灾备手段，不能替代持久盘；跨实例恢复要求各实例使用相同的 `SESSION_SECRET`。

安全与边界：公开列表不会暴露私密邀请令牌；聊天、语音信令、恢复快照和房间控制接口均经过成员身份、房主权限、体积和频率限制。语音只交换浏览器会话所需的 SDP / ICE 信令，服务器不保存音频。请勿把恢复快照上传到公开网盘；Render 当前没有持久盘，实例重建后仍可能需要手动恢复。

账号注册登录扩展：邮箱、手机号、QQ 与微信

新增登录入口：“我的 → 注册 / 登录”现在支持邮箱验证码、手机号验证码、QQ 官方授权和微信官方授权注册登录；邮箱与手机号也可以用于密码登录、验证码登录、找回密码和绑定现有账号。原有昵称密码登录、一次性恢复码、多设备同步与匿名试玩继续保留。

邮箱与手机号验证：邮箱和手机号必须先通过验证码确认归属，才能注册或绑定。验证码有效期 10 分钟、最多尝试 6 次，60 秒内不能重复发送，同一联系方式每小时最多接收 5 次。发送频率还会按玩家身份和来源网络分别限制，减少恶意轰炸、批量注册和额度滥用。

QQ 与微信授权：QQ、微信采用官方 OAuth 授权流程，不在本站收集对应平台密码。每次授权都使用一次性 state 状态，并校验浏览器和账号会话，防止登录 CSRF 与串号绑定。本站不保存 QQ、微信 access token，只保存平台账号标识、公开昵称和头像地址。

身份与绑定安全：邮箱、手机号、QQ openid 和微信 openid 的明文只进入加密账号文件；用于登录查找的反向索引只保存 HMAC 不可逆摘要。绑定验证码和 OAuth 绑定状态都会绑定发起操作的账号，切换到其他账号后不能复用。账号不会允许解绑最后的登录方式，避免把自己永久锁在账号外。

密码、恢复码与设备：QQ、微信首次创建的账号可以先使用第三方授权登录，随后在账号安全页面设置密码，并获得一次性恢复码。密码使用 scrypt 加盐哈希；恢复码只显示一次并只保存加盐哈希。多设备可共享资料、剧本、存档、好友关系和私信，也支持单设备撤销、退出其他设备和修改密码后自动退出其他设备。

安全日志：昵称密码注册与登录、邮箱或手机号注册与登录、QQ 或微信授权登录、验证码找回、设置或修改密码、身份绑定与解绑、设备撤销、API Key 更新或删除、昵称修改、举报和数据导出都会写入个人安全日志。日志只保存来源 IP 的不可逆指纹，不保存密码、验证码、完整 IP 或 API Key。

注销与数据删除：已设置密码的账号在注销时需要当前密码；只有第三方登录且尚未设置密码的账号必须提供一次性恢复码。注销会同步删除账号、邮箱和手机号绑定、第三方身份、设备会话、资料、剧本、存档、帖子、好友关系、私信、设备记录和安全日志，并清理相关登录索引。公开内容若曾被他人复制或转发，仍无法追回外部副本。

玩家互动：玩家空间继续支持关注、好友请求、好友私信、拉黑和举报。私信仅限好友；拉黑会解除关注和好友关系，并阻止私信及相关公开内容显示。举报会进入后台记录供管理员处理。

测试情况：本次已完成邮箱注册与密码登录、手机验证码登录、手机号找回、身份绑定与解绑、重复身份拦截、跨账号串绑拦截、普通昵称登录、服务重启后登录、注销后索引清理，以及伪造 OAuth 状态拦截。网站首页、账号接口、安全响应头和匿名试玩入口均已复核。

小号与额度说明：系统会根据签名浏览器标识、来源网络指纹、注册频率和账号级额度记录风险信号，并在后台标记可能需要人工审核的账号。但清除 Cookie、使用无痕模式、更换浏览器或网络仍可能绕过，因此无法保证 100% 识别小号。联系方式和第三方登录也不能替代人工审核。

当前配置状态：登录功能和页面已经上线；QQ、微信、邮箱和短信按钮是否可用，取决于站长是否在云端配置对应平台的已审核应用与发送服务。QQ 和微信需要开放平台应用资质，短信需要实名模板，邮箱需要已验证的发件域名。尚未配置的平台会明确显示为灰色禁用状态，不会伪造发送成功或授权成功。

隐私说明：邮箱和手机号属于个人联系方式，仅在你主动选择验证、绑定或找回账号时处理。验证码记录会在过期后清理；你可以从账号管理页面解绑，也可以在满足身份验证后注销账号并删除相关绑定。

交互性能、推演体验与安全保障综合更新

交互性能：玩家资料、在线状态、剧本目录和系统设定增加短时缓存，避免每次签到与推演重复读取磁盘；回合接口改为只回传本轮新增内容，长剧情不再反复传输整段历史；HTML、CSS 和 JSON 使用异步压缩，带版本号的前端资源启用长期缓存。

推演与联机体验：推演等待区会显示当前处理阶段和已等待时间；可信资料同步改为后台预热，不再阻塞第一段正文；在线心跳会按人数自动降频，页面隐藏时暂停；联机房间没有变化时只返回极小的状态标记，剧本创建、删除和恢复后会立即刷新缓存。

交互流畅度：历史回合、反馈列表和重复轮询增加变化检测，没有新内容时不再重复重建页面；网络中断会显示明确原因并保留失败前的行动输入，避免一直转圈或重复提交。

账号与隐私安全：个人资料、私人笔记、GM 提示词和自带模型配置使用 AES-256-GCM 加密落盘；玩家身份使用服务端签名 Cookie；私密剧本按可见范围校验；跨站写入、脚本注入、上传伪造、内网探测、云元数据访问和 DNS 重绑定均被限制。

抗攻击与资源保护：全站连接数、在途请求、请求频率、模型并发、等待队列和默认模型每日调用均有硬上限；外部链接与玩家自带模型地址只允许公开网络；后台登录、备份、隐私导出和删除等敏感操作有独立限流。

安全边界：应用层措施可以降低过载、越权和费用风险，但不能替代平台级网络防护。大规模 DDoS 仍需 Cloudflare 等边缘服务清洗；Render 当前没有持久盘，实例重建仍可能清空数据，请站长定期下载完整备份，并建议在模型平台设置预算告警。

2026-11-28
网络异常时不再“转圈一小时”

针对部分玩家遇到的「启动失败：Failed to fetch」做了修复：开局和行动请求现在都有明确的时间上限；写操作不会自动重复发送模型请求，避免服务器已经推演后因响应丢失而重复推进或重复扣费。真的等不到响应时会直接说明原因（网络中断，或站点正在重启），而不是让页面一直转下去。行动提交失败时，你刚写的内容会保留在输入框里，不会白写。在线人数的判定也从 8 秒放宽到 25 秒，手机切到后台或网络抖动一下，不会再立刻从在线列表里消失。如果你再次看到类似提示，等十几秒后刷新确认当前进度，再决定是否重试。

2026-11-28
交互与推演性能优化

账号和在线状态改为内存缓存，剧本目录不再在每次开局和回合推进时重复扫描；回合接口改为只回传本轮新增内容，并启用异步文本压缩。在线心跳会根据人数自动降频，页面隐藏时暂停；联机轮询在内容没变化时只返回极小的状态标记。推演等待时会显示当前阶段和已等待时间，可信资料同步也改为后台刷新，不再阻塞第一段正文生成。

身份与账号：本站允许匿名试玩，也提供可选注册账号。玩家可以只用昵称和密码，也可以自愿绑定邮箱、手机号、QQ 或微信。邮箱和手机号必须先通过验证码确认归属；第三方登录只读取平台提供的账号标识、公开昵称和头像，不保存访问令牌。更换匿名浏览器、使用无痕模式或清除 Cookie 会导致匿名身份丢失；注册账号可通过已绑定方式、密码和一次性恢复码重新登录。

设备与安全记录：为支持多设备同步和设备撤销，系统保存随机设备 ID、浏览器类型、最近使用时间和加密账号数据。登录、密码、恢复码、API Key 配置、设备撤销和数据导出会产生安全日志；日志只保存来源地址的不可逆指纹，不保存完整 IP 地址、密码或 API Key。

收集的数据：昵称、简介、头像、私人笔记、主题与语言设置；剧本、角色预设、社区帖子、留言、评论、房间与游玩存档；关注、好友、私信、拉黑和举报记录；为运行和安全目的产生的在线状态、设备与基础访问信息。

公开内容：设置为公开的剧本、社区帖子、留言、评论、昵称和头像可能被其他玩家看到、复制或转发。请勿发布身份证号、住址、电话、账号密码、API Key 或其他敏感信息。设置为“仅自己”的剧本不会出现在他人剧本列表中。

创作者权利：创作者保留其原创作品署名权，可随时修改署名、可见范围或删除自己的剧本。平台仅按你的可见性设置存储、展示和提供给符合范围的玩家游玩，不会把作品冒充为平台原创。

联系人可见：联系人范围只依据对方不可自行伪造的随机玩家 ID 匹配。昵称可被任意修改，因此不再作为访问控制凭据。联系人可见仍不等同于高强度加密，请勿用它承载账号密码、真实住址或其他高风险秘密。

AI 处理：只有开局、回合推演和联机推进需要把当前剧情、角色、设定和行动发送到所选 AI 服务。使用网站默认模型时数据发送到网站配置的模型服务商；使用自定义 API 时发送到你填写的服务商。本站不把这些内容用于出售或广告画像，也不会把密钥展示给其他玩家。房间语音采用浏览器点对点连接，服务器只转发建立连接所需的信令，不保存音频；STUN 服务可能看到双方网络地址。

保存与删除：个人资料、私人笔记、GM 提示词和自带模型配置会使用 AES-256-GCM 加密保存。你可以在下方导出个人资料、剧本、预设、存档、帖子和留言，也可以删除当前浏览器身份下的个人数据。删除会移除服务器中的对应活动数据；已被他人复制、转发的内容无法追回，手动备份文件也可能保留历史副本。

你的选择：你可以关闭搜索发现、个人空间、活动身份展示和在线人数计入，也可以设置新剧本默认仅自己、联系人可见或公开。关闭活动身份不会删除已有公开内容，但之后显示的昵称和头像会匿名化。
